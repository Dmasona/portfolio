Portfolio Showcase 4

This is a cover design created for the Cyber Star Digital Magazine.

Purpose of the Project

This project focuses on designing a digital magazine cover for Cyber Star Magazine featuring Faye Atwell, one of the main characters from the animated web series Knights of Saturn. The objective is to increase digital sales and expand the magazine's market reach through an eye-catching cover design.

Tools and Skills Used

  • Move Tool: Used to reposition various design elements on the canvas, including the Faye Atwell artwork and magazine text.
  • Gradient Tool: Used to create a smooth blend of colors in the background, helping the featured artwork stand out while adding visual depth and interest.
  • Horizontal Type Tool: Used to create all horizontal text on the magazine cover. Additional text effects were applied to enhance visual appeal and strengthen the publication's branding.
  • Vertical Type Tool: Used to create the vertical text elements featured on the magazine cover layout.
