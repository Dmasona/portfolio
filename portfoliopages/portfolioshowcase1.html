This is a character design that was created for the Literature Royale nonprofit organization.

Purpose of the Project

This project aims to design a character for an online reading and literacy campaign for a mid-sized non-profit organization. The objective is to increase literacy among children and teens, encourage reading, and support local libraries.

Tools and Skills Used

  • Selection Tool: Used to move objects and elements of Tabitha's character design around the canvas.
  • Free Transform Tool: Used to resize the library background, cartoon cat, and other design elements. It was also used to rotate and adjust various parts of the character.
  • Rectangle Primitive Tool: Used to create Tabitha's hair, eyebrows, nose, arms, neck, torso, and legs. Several shapes were converted into drawing objects to simplify editing and construction of additional character features.
  • Oval Primitive Tool: Used to create the head, ears, eyes, mouth, neck, and collar. Drawing objects were utilized to allow for easier editing and refinement of details such as teeth and the tongue.
  • Bone Tool: Used to rig the character and create a smoother waving animation. Portions of the left arm were converted into symbols to support animation.
