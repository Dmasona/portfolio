Portfolio Showcase 1


This is a character design that was created for the Literature Royale nonprofit organization.

Purpose of the Project: This project aims to design a character for an online reading and literacy campaign for a mid-sized non-profit organization. The objective is to increase literacy amongst children and teens, encourage reading, and to support local libraries.

Explanation of Tools and Skills: Selection Tool: I used this tool to move objects and aspects of Tabitha’s character design around on the canvas. Free Transform Tool: I used this tool to resize both the library background and the cartoon cat to better fit onto the canvas of the character design. I also used this tool to resize or rotate multiple aspects of Tabitha’s character design. Rectangle Primitive Tool: I used this tool to draw Tabitha’s hair, eyebrows, nose, arms, neck, upper torso/body, and legs. I converted the arm into a drawing object in order to make it easier to create the hands of the character. I also converted the legs into a drawing object to make adding the lower torso aspects and other elements of the character more seamless. I also used this tool due to its editing capabilities after I’ve drawn my shapes. Oval Primitive Tool: I used this tool to draw the head, ears, eyes, mouth, neck, and collar of the Tabitha character. I also converted the mouth into a drawing object so that I could easily add the teeth and tongue of the character. Furthermore, I converted the neck collar into a drawing object as well. Moreover, I used this tool due to its editing capabilities after I’ve drawn my shapes. Bone Tool: I used this tool to rig the character design and to make the waving animation look more fluid. I also converted parts of the left arm into a symbol so that it could be animated.
