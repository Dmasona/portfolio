Portfolio Showcase 2

This is an animated infographic that was created for the Young Writers of Tomorrow nonprofit organization.

Purpose of the Project: This project aims to create an animated infographic that explains the writing process for the nonprofit organization Young Writers of Tomorrow. The objective is to create an animated infographic that explains the writing process in simple terms.

Explanation of Tools and Skills: Selection Tool: I used this tool to move around different elements on the stage. I also used this tool to select the elements on the stage that I wanted to convert into a symbol. Free Transform Tool: I used this tool to resize and rotate different elements on the stage. Text Tool: I used this tool to create all the text present within the infographic. Rectangle Primitive Tool: I used this tool to create the steps of the writing process highlighted on the infographic. I also used this tool due to its editing capabilities.
