Portfolio Showcase 3

This is photo of AJ Cooper that was restored for a local museum.

Purpose of the Project: This project aims to restore an old, ruined, and damaged portrait. The objective is to restore the damaged photo to a condition where it will be suitable to be used in an upcoming exhibition at a museum.

Explanation of Tools and Skills: Spot Healing Brush: I used this tool because it’s efficient and quicker in restoring areas of the photograph, especially in larger sections or portions. Healing Brush: I used this tool because it allowed for more manual control to choose which aspects of the portrait, I wanted to sample from in order to effectively restore the photograph. This was especially evident when it came to the smaller trickier sections of the photograph. Clone Stamp: Similar to the Healing Brush Tool I used this due to its manual control and to help restore trickier tinier sections of the photograph.
