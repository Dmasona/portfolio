This is a restored photograph of AJ Cooper that was repaired for a local museum exhibition.

Purpose of the Project

This project focuses on restoring an old, damaged portrait. The objective was to repair the photograph and return it to a condition suitable for display in an upcoming museum exhibition.

Tools and Skills Used

  • Spot Healing Brush: Used to efficiently repair larger damaged areas of the photograph and speed up the restoration process.
  • Healing Brush: Used for more precise restoration work by allowing manual selection of source areas to sample from. This was especially useful when repairing smaller and more complex sections of the image.
  • Clone Stamp Tool: Used to manually copy image details from one area to another, helping restore difficult and highly detailed portions of the photograph.
